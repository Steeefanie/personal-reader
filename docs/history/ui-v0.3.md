# v0.3 原生界面改版

本文记录 0.3 的历史界面设计，采用原生 Views、Readium EPUB 与 PDFium 正文渲染，沿用原进度协议。当前界面和阅读引擎见 [项目说明](../../README.md)。

## 页面

- 书库：标题与导入/搜索动作，继续阅读区，小封面列表，作者、格式与进度，右侧更多菜单及三种排序。作者只使用出版物提供的元数据，不从文件名猜测。
- 网盘：目录作为主体；格式、大小、是否已下载显示在行内。缓存书籍直接打开；下载及同步仍由现有服务处理。账号、二维码绑定、历史合并、冲突、错误及解除绑定收进连接设置。
- 设置：默认排版、当前空间进度文件导入/导出、网盘连接入口及版本信息。
- 阅读：中央点击显示上下工具栏，翻页时隐藏。上方返回、书名、添加书签及更多；下方位置、目录、搜索、排版/页码、书签。EPUB 百分比仅使用 totalProgression，缺失时显示“已开始阅读”，避免把章节内进度当作整书进度。

统一使用实色白底、黑色文字、单色路径图标、细分隔线和至少 48dp 动作目标；关闭列表 ItemAnimator，未增加动画、模糊或玻璃资源。顶部标题 28sp，书名 18sp，主文字 16sp，辅助文字 12–13sp。排版面板按字号、行距、页边距、系统字体分组；系统字体较大时步进控件分行排布。

## 元数据和兼容性

Room 升级至 v3，仅增加 book_metadata；v1→v2 与 v2→v3 顺序迁移。新表不承担同步业务，不覆盖原进度。书籍列表由当前账号空间的书籍、阅读位置和本地元数据组合，账号切换后重订阅。

只对可见区域附近最多十本及继续阅读项逐本提取作者/封面。原图先检查边界并采样，最终灰度 PNG 不超过 320×480；文件缓存可由系统回收，内存 LRU 上限 8 MB。无有效封面时使用标题占位。封面提取不触发网络下载。

## 复现验证

历史 PresentationTest 使用自建 EPUB 和封面，覆盖作者、无封面／损坏封面、灰度尺寸、缓存恢复、PDF 缩略图、整书进度及页面导航。当前构建和定向模拟器测试命令见 [开发说明](../development.md)。

PresentationTest.libraryAuthorSearchNavigationAndScreenshots 会在应用 cache 中保存 ui-*.png。可传 instrumentation 参数 previewSuffix 为不同屏幕保留截图。截图为模拟器真实界面，自建书目仅作版式展示，不随正式安装包预置。

该版本依赖系统刷新策略；残影、实体／蓝牙按键及休眠唤醒未完成真机验证。
