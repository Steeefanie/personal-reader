## 0.1.0：本地阅读链路

- EPUB/PDF 导入、SHA-256 去重、实际导航翻页、退出保存及重新打开恢复位置。
- 损坏文件拒绝入库、中文 EPUB 搜索、PDF 文本提取、DataStore 设置持久化、Room 合并及事务回滚。
- JSON 往返、书签删除记录、未知版本、非法哈希／位置、重复记录、格式冲突及 PDF 缩放边界。
- 修正 Readium 3.1.2 PDFium 适配中的零基页索引与一基页码混用；加载恢复期间避免覆盖原位置。
- 该版本不含云盘联网功能；其权限结论不适用于后续版本。

## 0.2.0：可选云盘客户端

- 模拟传输覆盖首次上传、412 冲突、上传期间新修改、响应丢失后确认、新设备恢复、账号隔离、401 撤销、503 保留及分页失败。
- Android Keystore 加密、密文不含原凭证、账号空间可见性及共享缓存删除保护。
- 数据库升级将旧数据保留在本地空间，不因迁移丢失书籍、进度或书签。
- 增加可选云盘所需联网权限；模拟接口通过不代表实际服务端已经兼容。

## 0.3.0：界面与书籍元数据

- 作者与灰度封面缓存、320×480 封面尺寸上限、无封面／损坏图片回退、缓存回收恢复及 PDF 首页面。
- 作者搜索、设置和云盘导航、目录、正文搜索、排版面板、点击翻页及工具栏显隐。
- 模拟器补充 320dp 窄屏、200% 系统字号检查；v1→v2→v3、v2→v3 升级保留既有记录。
- 静止书库约 25 秒采样记录 0 新帧，仅说明该窗口的渲染情况，不用于推算真实耗电。

## 0.3.1：同步与大文档

- 单书紧凑 JSON、8 MiB 边界、旧缩进记录压缩、CursorWindow 分块读取和 Unicode 完整性。
- 人造 23,000 条书签用于边界测试，不能据此估计常规用户的单书记录大小。
- 262 份独立进度中第 224 次读取被限流；重建服务与数据库后保留退避，读取剩余 39 份，已接受的 223 份不重读，不发 PUT。
- 书签冲突副本、失败索引待办及账号切换隔离。详细变更见 [同步修复说明](sync-fixes-v0.3.1.md)。

## 0.4.0：书库与排版

- 默认四列宫格、双栏列表、逐屏按钮、全宽面板，以及窄屏和大字号布局检查。
- 字号 16～36、默认 22；行距及边距七档。该版本内置两套思源字体，后续 0.5.2 已移除，不能据此判断当前 APK 的字体资产。
- 当时基于 WebView 的 EPUB 引擎完成 zh-TW 横排、翻页方向、字号变化后页数更新及显示开关检查。
- 静止阅读稳定后采样 10 秒记录 0 新帧；该结果仅适用于对应版本和采样窗口。
- 该版本 ARM64 包为 33,123,447 字节，字体资产合计 18,747,116 字节，沿用既有签名。设计说明见 [0.4 界面与排版](ui-v0.4.md)。

## 后续记录与验证边界

0.5.2～0.5.6 的版本、安装包摘要和专项检查见 [版本记录目录](../releases/)。工程更名保留 Android 包名和签名；路径迁移不是应用功能，也不作为设备兼容性依据。

历史模拟器结果均不能代替 ARM64 真机安装、墨水屏刷新／残影、实体与蓝牙按键、休眠和长期耗电。实际 HTTPS、手机授权与跨设备云盘同步须按接口契约另行联调。复杂大文件、存储耗尽、强制终止及不同 Android 版本的运行范围以具体版本记录为准。
