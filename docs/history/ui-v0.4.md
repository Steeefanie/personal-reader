# v0.4 界面与阅读排版

本文记录 0.4 的历史实现；后续已移除内置中文字体，并在 1.0.0 改用原生 Canvas EPUB 排版。当前功能见 [项目说明](../../README.md)。

该版本应用显示名称改为“图书”，包名保持 `top.steeefanie.leafreader`。版本 0.4.0 / versionCode 5。沿用 Room v3、手动进度 schemaVersion 1 和每书一份云端 JSON。

## 书库与导航

- 默认四列封面宫格，切换后为双栏列表，列表封面最大宽度由原 56dp 提高至 88dp。布局偏好保存在本机，重新打开后保留。
- 修正空书库、标题栏的 RecyclerView 宽度，避免“从一本书开始”等文字逐字换行。继续阅读改为紧凑一行，去除页头装饰文案，增加内容空间。
- 单色图标、实色背景、灰度封面。启动图标内部图形缩至原 90%，原描边从 2 调为 1.8。
- 底部三项导航配右侧上下翻屏胶囊；箭头各占相同宽度，居中对齐，窄屏保留最小点击范围。书库、网盘、设置、长面板无动画翻屏；阅读界面箭头用于上一页、下一页。

## 页面与面板

`PaperPanel` 保持原操作回调语义，展示为全宽下半屏面板或全屏页面：白底、细分隔线，无模糊、渐变、遮罩变暗、阴影及进入退出动画。目录、书签、搜索结果、账号管理、连接和二维码页使用全屏；短操作、确认及排版使用下半屏。系统文件选择器不在应用自行绘制范围内。

字体面板采用四行分组控件：圆形加减按钮、带等距刻度的横条与白色圆形滑块；下方显示当前字体和字体网格。高系统字号或窄屏下改用可滚动全屏排版页。刻度点击和加减操作即时更新面板数值，点击“应用”后保存和重新排版，“取消”保留原设置。

| 设置 | 档位 | 默认 |
| --- | --- | --- |
| 字号 | 16、17、18、19、20、22、24、27、30、33、36 | 22 |
| 字重 | 300、400、500、600、700、800、900 | 400 |
| 行距 | 1.2、1.4、1.6、1.8、2.0、2.2、2.4 倍 | 第 4 档，1.8 |
| 边距 | 0.25、0.5、0.75、1.0、1.25、1.5、1.75 倍 | 第 4 档，1.0 |

行距、边距均为七档、六个间隔。边距倍率作用于 Readium 的基础页边留白，不等同固定毫米。字号是排版名义数值，Readium 内部转换为以 16px 根字号为基准的倍率，正文段落在模拟器验证为 22px；标题仍保留相对字号层级，不把所有元素强制变成同样大小。旧版默认的 125% 升级为 22，其余已保存倍率换算至最近一档，新安装默认 22。字号设置只保存在 DataStore，不进入进度交换文件。

## 字体

该版本内置思源宋体、思源黑体，使用官方 CN 地区可变 TrueType WOFF2 原文件。中英文使用同一字体家族，缺失字符由系统后备字体补充；仍提供系统无衬线、系统衬线和系统等宽选项。初始默认系统无衬线，用户选择后持久化。

字重通过 Readium 转为 CSS `font-weight`，可变字库在支持范围内插值。当前界面提供 300～900 七档；400 常规、500 中等、700 粗体。字体声明与资源由本地 Readium 资产入口提供，选用时加载，无外部字体网络请求。系统字体实际可用字重取决于设备。

完整 SC 版可变字库曾在模拟器旧 WebView 83 上触发解码后超过 30MB 的拒绝加载，现使用官方 CN 地区子集；两份解码尺寸分别约 17.8MB、25.2MB，加载测试通过。字体资产共 18,747,116 字节，会增加安装包体积。未自行修改字库，许可与来源记录随当时版本提供；这些字体资产已在 0.5.2 移除。

## EPUB 与显示设置

zh-TW 元数据的 EPUB 样例触发了排版方向兼容问题。Readium 自动推断竖排时会启用滚动模式，造成文本方向和翻页操作不符合预期。v0.4 明确设定 `verticalText=false`、`readingProgression=LTR`、单栏、无滚动和无动画翻页，保持原 EPUB 文件不变。

EPUB 底部显示本章“当前屏幕页 / 总屏幕页”，采用 Readium 分页回调。排版变化后通过有限次 DOM 测量更新页数，处理首个 Locator 未变化而没有分页回调的情况。测量只在设置变化时运行数次，不在静止阅读时持续轮询。PDF 使用文件实际页码。

设置页新增“阅读时显示页码”“阅读时显示系统状态栏”，默认均开启。页码使用独立底部空间，不覆盖正文；隐藏后释放空间并重新分页。系统状态栏开关仅作用于阅读窗口。进度恢复仍采用内容 Locator；字号、行距或屏幕变化后的显示页码允许变化。

## 验证边界

自动化测试资源和界面截图使用自建 EPUB、PDF 及封面。外部 EPUB 兼容性检查通过可选 `epubPath` 参数执行，书籍不随测试资源分发。

该版本结果见 [历史验证记录](validation-before-1.0.0.md)。模拟器通过不能替代 Leaf5+ 真机刷新、残影、硬件按键、蓝牙翻页器及休眠耗电验收。
