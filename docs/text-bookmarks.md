# 文字书签与返回原处

EPUB 使用原生 Canvas 阅读与选字；Readium 提供出版物模型和 Locator 数据结构。PDF 提供页位置书签。

## 操作

长按 EPUB 正文并调整选区，点附近无阴影的“添加书签”保存划线；点划线出现“取消书签”。划线点击优先，不同时翻页；选择期间暂停滑动和按键翻页。默认书签名称为选文，列表按“章节名：文字摘要”单行省略。同时支持不含文字范围的位置书签，位置书签不会给句子划线。

PDF 右上角提供添加／取消本页书签，底栏查看所有书签；PDF 引擎不提供选字划线，扫描件不做 OCR。

## 锚点与交换

JSON 为 schemaVersion 1，Locator 可包含：

- `locations.nativeBodyOffset`：原生章节正文中的位置。
- `locations.readerTextRange`：version=1、unit=utf16、正文及范围起止位置；原生记录带 `engine: native`。
- `text.highlight`、`text.before`、`text.after`：选文及有限前后文。
- `locations.cssSelector`：标准 CSS 选择器定位信息。

换字号后重新排版，以选文、偏移和上下文重新定位；显示页码不作为文字锚点。选文最多 16000 个 UTF-16 单元，名称最多 1024 个字符。书签取消保留 deleted 与更新时间，合并保留不同 ID，同 ID 按更新时间和删除规则处理。

服务端应保留合法 Locator 扩展字段，不重写范围为页码。具体云盘端的字段保留与跨设备还需真实联调。

## 跳转返回

目录、搜索、书签、PDF 页码、云端位置及 EPUB 内部链接跳转保留前一位置，显示上栏下方的“返回原处”胶囊。PDF 同时保留缩放和页内位置。连续跳转记录最近出发点，不维护多层浏览历史。

有效手动翻页后隐藏；打开面板、字号重排、点击空白以及已到顶／底的无效翻页不清除。当前版本实测范围见 [验证记录](../VALIDATION.md)。
