# 图书 0.5.3 验证记录

日期：2026-11-07。versionCode 9，最低 Android 7.0 / API 24，目标 API 35。

## 变更

- 不嵌入思源字体；字体显示顺序为自带中文名、常见别名表兜底、原始名称。保留原始族名供搜索核对。索引 70 组常见字体名称、75 个文字体系对照，原始 9,094 字节、APK 内压缩后 2,533 字节；没有新增字库或预览图片。
- 字体选择页提供中文／全部筛选、中英文及别名搜索、实际本机字体渲染的中英文样例、可用字重。仅为可见行异步加载字体，缓存最多 6 个原生 Typeface。
- EPUB 增加段距七档：0、0.25、0.5、0.75、1、1.25、1.5，默认 0.75，由 DataStore 保存；字号默认 22，原有字号、行距、边距档位保留。PDF 仍保持原版排版。
- 全局界面辅助字 16sp、正文／按钮／输入框 18sp、列表标题及目录项 20sp、面板标题 22sp、页面标题 30sp，跟随系统字体缩放。相应扩大排版控件及页码栏。
- 阅读底栏、目录、排版面板共用返回位置；阅读底栏返回与目录之间加短竖线，进入面板时隐藏。上栏书名、章节和进度字号一致，间距增大，长书名限制宽度。
- 翻屏胶囊高度 48dp，底栏内上、下、右侧 8dp。框线、箭头和中央线同为 2dp。单方向不可滚动时该半边外框及箭头灰显，中线黑色；两侧均不可滚动时整枚胶囊包括中线均灰显，并禁用点击。
- 滚动状态仅由滚动和布局事件更新，离开窗口时移除监听，无新增轮询。ListView 按约九成可见高度立即翻屏。
- 主导航图标 36dp，未选中为轮廓、选中为实面，移除下横线且不加独立外围框。书库双书造型复用同一轮廓旋转 180°，尖角在轮廓内、不外翘。云盘图标无内部横线，云盘文件列表书籍图标保持原样。
- 显示名称统一为“云盘”，现有类名、接口、进度交换协议和数据库版本不变。宫格／列表切换图标的左侧两个方框保持相同大小与位置，书籍布局本身未因该图标修改而改变。

## 构建与实际验证

- JDK 17、Gradle 8.14.3、AGP 8.10.1、Kotlin 2.1.21、Readium 3.1.2；离线 assembleDebug、assembleDebugAndroidTest、assembleRelease 成功。
- 48 项 JVM 单元测试通过；Android Lint 0 错误、50 警告，包含依赖版本、国际化、自定义 View 与 KTX 写法提示。
- Android 11 / API 30、WebView 83 模拟器：完整仪器测试 35 项通过，1 项可选外部 EPUB 测试因未提供文件路径跳过，无失败。
- 已实际检查：EPUB／PDF 导入、搜索和进度恢复；系统中文黑体／宋体 TTC 字面实际加载；字体搜索与真实字形像素；段距调整后实际 CSS 段落边距增大；单屏、空列表、顶部、底部按钮状态及中线像素颜色；四列宫格与双栏列表；云盘相关既有离线及同步测试。
- 返回按钮位置通过屏幕坐标断言：目录、排版面板相对阅读工具栏的横、纵坐标差不超过 2px。上栏书名与章节／进度字号一致，面板打开时分隔线隐藏。
- 另外运行 1.5 倍系统字体下的主要界面导航与返回位置检查，1 项通过；随后恢复模拟器字号。
- 阅读静置 7 秒后采样 10 秒，gfxinfo 显示 Total frames rendered: 0。
- 仪器测试使用同源 Debug 包和自建 EPUB／PDF；测试夹具不包含外部书籍或设备字库。
- ARM64 Release 已完成构建、签名及资源检查，尚未完成真机安装验证。
- 未运行 Android 7 真机验证；低版本 API 有版本保护。Android 7 无法原生预览 TTC 非首字面时会明确提示，阅读仍用原有内存提取方式。无法读取的厂商私有字体不列入选项。
