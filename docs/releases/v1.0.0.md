# 图书 1.0.0

首个正式公开版本，面向 Android 墨水屏设备，支持简体中文界面和 EPUB / PDF 本地离线阅读。

## 安装包

- 下载 `personal-reader-1.0.0-arm64.apk`，适用 Android 7.0 及以上 ARM64 设备，约 13.72 MiB。
- 版本 1.0.0；不同来源自行构建的 APK 签名不同，无法直接覆盖安装。
- 附件 `SHA256SUMS.txt` 提供校验值；源码 ZIP/TAR 由 GitHub 从本标签生成。

## 功能

- 四列封面宫格与双栏列表，本地批量导入、去重、搜索及排序。
- EPUB 原生 Canvas 分页、目录和搜索；支持字号、实际字重、行距、段距、边距及本机字体预览，不内置中文字体包。
- 长按文字添加划线书签，点击划线取消，保留文字范围和上下文；同时支持普通位置书签，跳转后可返回原处。
- PDF 单页、缩放、页码、目录、文本层搜索及页书签。
- 黑白界面、无阴影全屏／下半屏面板、上下翻屏胶囊，可控制页码、状态栏和触摸翻页。
- 可选独立云盘接口：设备绑定、逐本上传下载、仅本地设置、单书 JSON 进度交换，以及文件和对应 JSON 的逐书删除。功能需要兼容服务端和相应授权。

## 数据与存储

本地书库与阅读状态由 Room 保存，支持手动 JSON 导入导出备份；设备凭证由 Android Keystore 加密保存，写入阅读记录前执行格式校验。

## 验证与边界

60 项单元测试通过；Android 11 模拟器 51 项通过、1 项可选外部 EPUB 测试跳过；Release Lint 0 错误、58 警告。APK v2 签名验证通过。完整说明见 [验证记录](../../VALIDATION.md)。

尚未完成 ARM64 真机验证；墨水屏刷新、休眠、按键、长期耗电及实际云盘联调仍需分别验证。复杂 EPUB 出版者样式未完整复现，显示总页数包含估算；不支持 DRM、OCR、PDF 重排、TXT、朗读或 AI。第三方说明见 [THIRD_PARTY_NOTICES.md](../../THIRD_PARTY_NOTICES.md)。
