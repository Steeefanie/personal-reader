# 图书 0.5.4 验证记录

日期：2026-11-07。versionCode 10，minSdk 24，targetSdk 35，ARM64。

## 修改

- 段距七档整体收紧，默认中间档由 0.75 变为 0.5。新档位为 0、0.125、0.25、0.5、0.75、1、1.25。使用 paragraphSpacingV2 设置键，旧值按原选中档位映射到新范围，保存后移除旧键，避免重复收紧。最紧档仍为 0，首个正值细分为 0.125，保留七个不同档位。
- 翻屏胶囊外框、中央竖线为 1.25dp，两个箭头保持 2dp。原高度、间距与独立灰显规则保留；不足一屏时中线也灰显。
- 书库、云盘、设置共用 72dp 最小标题栏高度和 20dp 左边距，标题垂直居中；书库搜索框左侧与标题间距由 12dp 增至 24dp，输入框高度调整为 48dp。
- 修复全文搜索清空结果时的闪退：共享文字适配器复制数据为可变 ArrayList，不再直接持有 Kotlin 只读列表。
- 字体预览行复用同一字体已完成或正在进行的加载结果，避免重复布局时不断重置预览及行高、影响底部翻屏状态。
- 图标造型、字体索引、云盘协议、数据库和阅读记录格式沿用 0.5.3。本版没有新增字体文件或设备专用刷新策略。
