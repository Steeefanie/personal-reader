# 图书 0.5.2 验证记录

日期：2026-11-07。versionCode 8，最低 API 24，目标 API 35。

## 变更

- 移除供用户选择的两套思源字体，共 18,747,116 字节，并移除对应字体许可页和资产引用。
- 默认跟随系统；兼容旧字体设置，优先映射本机简体中文宋体或黑体，缺失时使用系统默认。
- 系统字体后台枚举、按字体族归组；静态字库仅提供真实字重，可变字库按 wght 范围提供百位档及范围端点。单字重控件禁用。
- 字库通过 Readium 本地资源拦截按需读取；TTC 所选字面在内存中提取，最多缓存 32 MiB。不联网下载、导出或向设备存储复制字库。
- 内部 Activity 的打开和返回显式使用零时长转场；半屏、全屏面板保持零动画，无阴影；不额外插入白屏或强制设备全刷。

## 实际验证

- JDK 17 / Gradle 8.14.3：assembleDebug、assembleRelease、testDebugUnitTest、lintDebug 成功；41 项单元测试通过。Lint 0 错误、42 警告，包括既有的依赖版本、国际化及自定义 View 警告。
- Android 11 / API 30、WebView 83 模拟器：完整仪器测试 34 项通过，1 项因未提供可选外部 EPUB 路径而跳过，无失败。
- 最终构建再次执行字体排版与界面导航两项测试，均通过。验证 Noto Sans CJK SC、Noto Serif CJK SC 的 TTC 字面实际由 WebView 加载；检查正文 22px、真实 CSS 字重，检查系统默认回退、单字重禁用及字号调整。
- 内部书库→设置→网盘导航检查 FLAG_ACTIVITY_NO_ANIMATION，目录底栏返回检查通过。未在普通安卓手机实测不同厂商的系统级转场。
- 自建 EPUB 静置 7 秒后采样 10 秒，应用 gfxinfo 显示 Total frames rendered: 0。
- 单元测试覆盖静态/可变字重、损坏字体、TTC 字面与提取结果校验和。
- 实际设备字体加载和转场效果尚未完成真机验证。
- 未运行 Android 7 真机/模拟器；低版本公开 API 入口有版本保护，Lint 检查通过。无法读取的厂商私有字库不会列入选项，不能保证读取所有设备的全部字体。
