# 图书 1.0.2

## 修复

- 修复 EPUB 中中文破折号可能显示不完整的问题。双字破折号连续显示，两端对齐时中间不插入字距，换行时保持完整。

## 安装

已安装正式版 1.0.1 的用户可在「设置 → 关于 → 检查更新」下载并覆盖安装。也可手动下载 `personal-reader-1.0.2-arm64.apk`，适用于 Android 7.0 及以上的 ARM64 设备。

附件 `SHA256SUMS.txt` 提供 APK 校验值。构建和测试范围见本版本的[验证记录](https://github.com/Steeefanie/personal-reader/blob/v1.0.2/VALIDATION.md)。
