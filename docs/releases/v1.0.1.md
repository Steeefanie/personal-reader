# 图书 1.0.1

## 更新内容

- 在「设置 → 关于」新增「检查更新」。应用从 GitHub Release 下载新版 APK，核验 SHA-256、包名、版本和签名后，由 Android 系统确认覆盖安装。
- 收紧阅读页的上下留白，按系统状态栏和页码的显示状态分别预留空间。
- 修复 EPUB 目录跳转在重新排版时丢失目标的问题，改进同一文件内的章节锚点定位。打开 EPUB 或 PDF 目录时会滚动到当前目录项并作标记。

## 安装

下载 `personal-reader-1.0.1-arm64.apk`，适用于 Android 7.0 及以上的 ARM64 设备。已安装官方 1.0.0 的用户可用此 APK 覆盖安装。应用内检查更新从 1.0.1 起可用。

附件 `SHA256SUMS.txt` 提供 APK 校验值。构建及测试范围见本标签的 [验证记录](https://github.com/Steeefanie/personal-reader/blob/v1.0.1/VALIDATION.md)。
