# 图书 0.5.6 验证记录

日期：2026-11-07。versionCode 12，minSdk 24，targetSdk 35，ARM64。

## 变更

- 书库标题行提供并列的宫格、双栏列表按钮，直接选择布局；实面表示当前视图，线框表示另一视图，无固定外框或选中横线。重复点击当前视图不触发布局重建。
- 默认四列宫格仅显示封面和书名，不创建作者、格式、进度或更多按钮。长按书籍仍可打开管理面板。
- 双栏列表继续显示封面、书名、作者、格式和进度，保留更多按钮。视图选择继续持久化；作者搜索不受宫格隐藏作者的影响。

- 离线 assembleDebug、assembleDebugAndroidTest、assembleRelease、testDebugUnitTest、lintDebug 成功。49 项单元测试通过，Lint 0 错误、51 警告。
- Android 11 / API 30 模拟器（1264×1680，300 DPI）PresentationTest 的 5 项检查全部通过，覆盖封面缓存、离线云盘、整书进度文案、宫格／列表及翻屏、主要界面导航和作者搜索。
- 宫格卡片断言仅有一个 TextView（书名）、没有 ImageButton、保留长按监听；列表卡片显示作者与更多按钮。切换前后检查两个按钮的 isSelected 状态，重开页面后验证列表选择及两栏布局保留。
