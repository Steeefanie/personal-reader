# 图书 · personal-reader

面向墨水屏的 Android 本地阅读器。支持无 DRM 的 EPUB、PDF，使用简体中文界面，书籍复制到应用私有目录后可离线阅读。云盘为可选的独立 HTTP 接口能力，不依赖任何指定网盘工程。

[下载 1.0.0 APK](https://github.com/Steeefanie/personal-reader/releases/tag/v1.0.0) · [使用与构建文档](docs/README.md) · [验证记录](VALIDATION.md) · [发布说明](docs/releases/v1.0.0.md)

## 安装

从 Release 下载 `personal-reader-1.0.0-arm64.apk`，在 Android 设备上允许安装该来源的应用后安装。最低 Android 7.0（API 24），此安装包适用于 ARM64 设备；x86 模拟器请自行构建调试包。

1.0.0 保持原应用包名和签名，可覆盖同签名的历史测试包。升级前可在设置中导出阅读记录。不同来源自行构建的 APK 可能签名不同，不能直接覆盖安装。

## 功能

- **书库**：系统文件选择器批量导入，SHA-256 去重，标题／作者搜索及排序；默认四列封面宫格，可切换双栏列表，书名单行省略，菜单完整显示。
- **EPUB**：Readium 解析出版物，原生 Canvas 分页；目录、正文搜索、点击／滑动／按键翻页、位置恢复，以及字号、字重、行距、段距和页边距设置。
- **字体**：跟随系统或选择应用可读取的本机字体，提供中文名称索引、实际字体预览和可用字重；不内置中文字体包。厂商私有且不可读取的字体不会显示。
- **书签**：EPUB 长按选字并添加划线，点击划线可取消；保存文字范围及上下文，保留旧位置书签。PDF 提供页书签。目录、搜索等跳转后可“返回原处”。
- **PDF**：PDFium 渲染、目录、页码跳转、缩放、适合宽度及文本层搜索。扫描件可阅读，不提供 OCR。
- **墨水屏界面**：白底黑字、无阴影面板、关闭页面转场；底栏提供上下逐屏按钮。可控制阅读页码、系统状态栏及触摸翻页。
- **阅读记录**：Room 本地保存，支持手动 JSON 导入导出；跨设备定位依据内容位置，显示页数不作为同步锚点。

EPUB 显示页数随排版和屏幕变化；当前整书页数由已测章节与未测章节的估算组成。原生排版处理常用正文、标题、图片等内容，不完整复现所有出版者 CSS 或复杂书籍版式。

## 使用

1. 在书库右上角点“＋”选择 EPUB 或 PDF。应用保留自己的副本，不修改导入时的外部原件。
2. 点封面或书名开始阅读。正文左右区域翻页，中央区域呼出工具栏；正在输入或选择文字时暂停翻页处理。
3. 宫格长按书籍，或在双栏列表点更多，打开管理菜单；菜单书名可多行显示。
4. 在设置中调整默认排版、阅读显示，或手动备份阅读记录。

不支持 DRM、密码 PDF、TXT、OCR、PDF 文字重排、朗读或 AI。卸载会删除应用私有目录，重要书籍应保留原件，阅读记录可手动备份。

## 可选云盘

在“云盘”或“设置 → 连接与账号”填写兼容服务的 HTTPS 根地址，通过服务提供的授权页绑定设备。设备凭证由 Android Keystore 加密保存；阅读器不接收登录密码，不跟随带凭证请求的跨站重定向。

- 绑定成功后，将未归属账号的本地书库和记录复制到该账号空间，原本地数据保留；其他账号空间的数据不转交。
- 阅读记录按**一份书籍文件对应一份单书 JSON**交换；相同文件改名仍按哈希识别。
- 书库可显示云端已有／待上传状态，逐本选择仅保留本地；书籍上传由云盘页“同步并刷新”触发，下载由用户点击触发。
- 已同步书籍可分别移除本地副本、云端副本，或两端一起删除。云端删除同时处理这一个书籍文件及对应 JSON，收到完整回执后才执行本机移除。
- 文件列表、上传、删除使用可选能力协商，服务未实现或设备未获授权时提示原因，不假定执行成功。服务端还须处理 ETag、删除标记、幂等和账号隔离。
- 阅读过程中暂停周期待办处理；退出阅读、网络恢复和前台手动操作按当前同步策略处理记录。不运行常驻后台同步服务。

接口文档：[基础契约](docs/drive-contract-v1.md)、[书库与上传扩展](docs/cloud-library-sync.md)、[单书删除](docs/cloud-book-deletion.md)。模拟接口通过不代表任意真实网盘已完成适配。

## 开发与目录

使用 Kotlin、原生 Views、单应用模块；JDK 17、Gradle 8.14.3、Android SDK 35，依赖版本固定在 Gradle 文件中。源码可独立构建，不需要相邻网站或网盘项目。

| 目录／文件 | 职能 | 是否进入 Git |
| --- | --- | --- |
| `app/src/main/` | 应用源码、原生资源及字体名称索引 | 是 |
| `app/src/test/` | JVM 单元测试 | 是 |
| `app/src/androidTest/` | Android 回归及自建测试书 | 是 |
| `tools/` | 构建和受限范围清理脚本 | 是 |
| `gradle/`、`gradlew*` | 固定版本构建入口 | 是 |
| `docs/` | 接口、开发、版本与历史说明 | 是 |
| `work/` | 本机工具链、缓存、私有签名和验证原始记录 | 否 |
| `outputs/1.0.0/` | 版本 APK 与校验值，APK 通过 Release 分发 | 否 |
| `app/build/`、`build/`、`.gradle/`、`.kotlin/` | 可再生成的构建产物和缓存 | 否 |

Windows 调试构建：

```powershell
$env:JAVA_HOME = '<JDK 17 目录>'
$env:ANDROID_HOME = '<Android SDK 目录>'
.\tools\build.ps1
```

构建流程、签名及测试见 [开发说明](docs/development.md)，目录边界见 [项目结构](docs/structure.md)，发布流程见 [发布 APK](docs/releasing.md)。第三方组件及许可见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

## 验证边界

1.0.0 的构建、测试数量及 APK 校验值以 [VALIDATION.md](VALIDATION.md) 为准。模拟器不能验证真实墨水屏的残影、刷新质量、实体／蓝牙翻页器和长期耗电；Leaf5+ 真机与实际云盘服务仍须分别验收。仓库不包含用户书籍、设备数据、账号凭证或签名私钥。
